1. Inheritance:
- Creature is the parent class.
- Dragon, Unicorn, and Phoenix inherit shared properties like name and health.

2. Polymorphism:
- attack() is defined differently in each creature class.
- Same method name, different behavior.

3. Association:
- Creatures can use MagicPotion objects.
- Potion increases health and is consumed after use.

4. Battle System:
- Battle class controls interaction between two creatures.
- Each round both creatures attack each other until one dies.
